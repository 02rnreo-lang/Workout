- 지난주 비교: 선택된 요일의 실제 날짜에서 정확히 7일 전 기록을 조회하도록 수정


=== KST 날짜 전면 수정 ===
- 모든 운동 날짜 계산을 Asia/Seoul 기준으로 통일
- UTC toISOString 때문에 날짜가 하루 전으로 저장되던 문제 제거
- 현재 주 월~금 날짜 계산 수정
- 지난주 비교는 선택 요일 날짜의 정확히 7일 전을 조회
- 주간 통계 범위도 한국시간 날짜 키 기준으로 계산
- 기존 잘못 저장된 기록은 최초 실행 1회 자동 보정
  (예: 2026-09-10의 금요일 기록 -> 2026-09-11 금요일)
- 정상 날짜에 이미 데이터가 있으면 덮어쓰지 않고 병합


=== 운동 고유 ID + 순서 변경 ===
- 각 운동에 고유 ID 부여
- 기존 인덱스 기반 운동 기록을 최초 실행 시 고유 ID 기반으로 자동 변환
- 운동 순서를 바꿔도 지난주 비교가 같은 운동 ID를 따라감
- 운동 카드에 ↑ / ↓ 순서 변경 버튼 추가
- 운동 이름을 편집해도 동일 운동 ID 유지
- 새로 추가한 운동도 고유 ID 자동 생성
- 기존 기록은 유지하며 자동 마이그레이션


=== v11 기록 호환 긴급 수정 ===
- 실제 구버전 기록 키가 0_0 형식인데 이전 변환기가 0-0만 찾던 오류 수정
- 구형 0_0 / 0-0 / 신형 exerciseId::set 형식을 모두 읽는 호환 레이어 추가
- 기존 기록을 v2 마이그레이션으로 안전하게 운동 ID 키로 변환
- 운동 이름 편집 시 고유 ID가 사라지던 문제 수정
- 순서 변경 후에도 운동 ID 기준으로 기록/지난주 비교 유지
- 지난주 비교 날짜는 선택 요일의 정확히 7일 전 사용


=== v13 운동 이름 기반 기록 매칭 ===
- 화면 순서/슬롯/ID가 아니라 운동 이름을 기준으로 새 기록 저장
- A-B-C -> C-A-D -> B-D-A처럼 매주 순서가 달라도 이름별 기록 유지
- 현재 D를 입력하면 지난주에 없더라도 더 이전 날짜까지 거슬러 올라가 가장 최근 D 기록 표시
- 각 세트에 당시 운동 이름 스냅샷 저장: 이후 루틴 순서/이름 편집이 과거 기록 표시를 뒤섞지 않음
- 기존 ID/인덱스 기록은 삭제하지 않고 읽기 호환 + 가능한 범위에서 이름 키로 복사
- 기록 화면도 저장 당시 운동 이름을 우선 사용

=== v14 사진 루틴 적용 ===
사진의 각 운동 행 기준으로 종목/순서/세트/반복수를 적용했습니다.
월 22세트 / 화 22세트 / 수 18세트 / 목 18세트 / 금 19세트.
※ 원본 이미지의 화요일 상단에는 21세트라고 적혀 있지만, 표시된 운동별 세트 합은 22세트(4+4+3+3+3+5)라서 운동별 표기를 우선 적용했습니다.
v13의 운동 이름 기반 과거 기록 검색 기능은 유지됩니다.


=== v16 운동명 자동완성 ===
- 운동 추가/편집 시 기존에 사용한 운동 이름 자동완성
- 현재 루틴 + 기본 루틴 + 과거 기록의 운동명을 후보로 사용
- 기존 이름을 선택하면 이름 기반 과거 기록과 정확히 연결
- '체스트프레스' / '체스트 프레스'처럼 공백만 다른 입력은 기존 이름으로 자동 통일
- 새 운동 이름은 그대로 새 운동으로 등록
